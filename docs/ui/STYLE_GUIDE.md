# UI Style Guide

## Wrappers
- AppScaffold: use for new screens to provide a TopAppBar and default content padding.
- SectionCard: use for grouped content blocks; title is optional.
- PrimaryButton: use for the primary action on a screen; defaults to full width.
- SecondaryButton: use for supporting actions; defaults to full width.
- StatChip: use for compact summary counters (for example, "Total: 9").

## Spacing defaults
- AppScaffold content padding: 16dp horizontal and 16dp vertical.
- SectionCard internal padding: 16dp with 12dp spacing between items.

## Rules
- Keep one primary action per screen (apply in later PRs).
